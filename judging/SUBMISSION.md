## What is judged

- Code on the registered repository's default `main` branch as it stands at 08:00.
- The README: what the project is and what the demo shows.
- The uploaded video, no more than two minutes.
- Four equally weighted criteria: Use of Mubit, Usefulness, Technical execution, Demo.

A branch or open PR is not the judged source. Merge the tested submission changes
that you want included. New submissions can replace earlier ones until 08:00;
the latest submission is judged. Upload a valid version early and replace it only
if there is a verified improvement before the cutoff.
